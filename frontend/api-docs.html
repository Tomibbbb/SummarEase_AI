Introduction

Welcome to the SummarEase API documentation. This guide provides information about how to interact with our REST API for text summarization services.

Base URL

All API URLs listed in this documentation are relative to: https://api.summarease.com/api/v1

For local development: http://localhost:8000/api/v1

Architecture Overview

SummarEase follows a microservices architecture pattern, with the following components:

Frontend

HTML/CSS/JavaScript client application

Backend API

FastAPI-based RESTful API

Authentication

JWT-based authentication

Database

PostgreSQL for persistent storage

Queue System

Redis + Celery for asynchronous processing

External API

Cohere API for text summarization

Authentication

SummarEase uses JWT (JSON Web Tokens) for authentication. To access protected endpoints, you need to include the token in the Authorization header.

POST

/auth/login

Authenticate a user and get an access token.

Parameters:
  • username (string): User's email
  • password (string): User's password
Example Request:
curl -X POST http://localhost:8000/api/v1/auth/login \
    -d "username=user@example.com&password=password123" \
    -H "Content-Type: application/x-www-form-urlencoded"
Response (200 OK):
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}

Users

POST

/auth/register

Create a new user account.

Parameters:
{
  "email": "user@example.com",
  "password": "password123"
}
Example Request:
curl -X POST http://localhost:8000/api/v1/auth/register \
    -H "Content-Type: application/json" \
    -d '{"email":"user@example.com","password":"password123"}'
Response (200 OK):
{
  "id": 1,
  "email": "user@example.com",
  "is_active": true,
  "credits": 10
}
GET

/users/me

Get current user information.

Headers:
  • Authorization: Bearer {access_token}
Example Request:
curl -X GET http://localhost:8000/api/v1/users/me \
    -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
Response (200 OK):
{
  "id": 1,
  "email": "user@example.com",
  "username": "user",
  "is_active": true,
  "role": "user",
  "credits": 10
}

Summaries

POST

/summaries/summarize

Create a new summary using the Cohere API.

Headers:
  • Authorization: Bearer {access_token}
  • Content-Type: application/json
Parameters:
{
  "user_id": 1,
  "text": "Long text to summarize..."
}
Example Request:
curl -X POST http://localhost:8000/api/v1/summaries/summarize \
    -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
    -H "Content-Type: application/json" \
    -d '{"user_id":1,"text":"Long text to summarize..."}'
Response (200 OK):
{
  "success": true,
  "summary": "Summarized text...",
  "summary_id": 1,
  "stats": {
    "processing_time_ms": 856,
    "input_tokens": 120,
    "output_tokens": 20
  }
}
POST

/summaries/

Create a new summary task.

Headers:
  • Authorization: Bearer {access_token}
  • Content-Type: application/json
Parameters:
{
  "original_text": "Long text to summarize...",
  "model_id": "summarize-xlarge",
  "min_length": 30,
  "max_length": 100
}
Example Request:
curl -X POST http://localhost:8000/api/v1/summaries/ \
    -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
    -H "Content-Type: application/json" \
    -d '{"original_text":"Long text to summarize...","model_id":"summarize-xlarge"}'
Response (200 OK):
{
  "id": 1,
  "user_id": 1,
  "original_text": "Long text to summarize...",
  "summary_text": null,
  "status": "pending",
  "model_used": "summarize-xlarge",
  "created_at": "2025-04-30T12:00:00",
  "completed_at": null
}
GET

/summaries/

Get all summaries for the current user.

Headers:
  • Authorization: Bearer {access_token}
Query Parameters:
  • skip (integer, optional): Number of records to skip (default: 0)
  • limit (integer, optional): Maximum number of records to return (default: 20)
  • status (string, optional): Filter by status (pending, processing, completed, failed)
Example Request:
curl -X GET "http://localhost:8000/api/v1/summaries/?limit=10&status=completed" \
    -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
Response (200 OK):
[
  {
    "id": 1,
    "user_id": 1,
    "original_text": "Long text to summarize...",
    "summary_text": "Summarized text...",
    "status": "completed",
    "model_used": "summarize-xlarge",
    "created_at": "2025-04-30T12:00:00",
    "completed_at": "2025-04-30T12:01:00"
  }
]
GET

/summaries/{summary_id}

Get a specific summary by ID.

Headers:
  • Authorization: Bearer {access_token}
Path Parameters:
  • summary_id (integer): The ID of the summary to retrieve
Example Request:
curl -X GET http://localhost:8000/api/v1/summaries/1 \
    -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
Response (200 OK):
{
  "id": 1,
  "user_id": 1,
  "original_text": "Long text to summarize...",
  "summary_text": "Summarized text...",
  "status": "completed",
  "model_used": "summarize-xlarge",
  "created_at": "2025-04-30T12:00:00",
  "completed_at": "2025-04-30T12:01:00"
}
